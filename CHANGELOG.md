# Changelog

## 1.1.1

- Added `Off` to the mode dropdown. Disable caching from the same widget, including when promoted to a subgraph.
- Removed `H3 Experimental` due to audio quality issues. Select `H3 Fast` or another supported mode in existing workflows.

`H3 Fast` remains the default. Safe, Fast, Aggressive, and Custom keep their existing cache behavior.
